# 🎓 Data Science & Data Analysis Using Python

## 📌 Overview
This project analyzes student academic performance using Python libraries — **Pandas**, **Matplotlib**, and **Seaborn**.  
It explores relationships between study time, gender, and final grades (G3) from the dataset `student-mat.csv`.  
The goal is to uncover insights about factors influencing student success.

## ⚙️ Features
- Data cleaning and validation  
- Statistical analysis (mean, correlation, and group comparisons)  
- Visualization of grade distribution and study time impact  
- Gender-based performance comparison  
- Insights generation using Python data analysis tools  

## 🛠️ Tech Stack
- Python 🐍  
- Pandas  
- Matplotlib  
- Seaborn  
- CSV data handling
